# Zijie Jin · Academic homepage

This single-page Jekyll site uses [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io). The current draft uses an initials avatar and bracketed text until profile details are supplied.

## Edit the homepage

- Update the author name, role, affiliation and public profile links in `_config.yml`.
- Edit the biography and selected papers or projects in `_pages/about.md`.
- To use a portrait, add the image to `images/` and set `author.avatar` to its relative path.
- To show a CV link, add a PDF to `files/` and set `author.cv` to its relative path.
- Keep section links in `_data/navigation.yml` aligned with the headings.

The generated local preview is `_site/index.html`. To rebuild it in a Jekyll environment, run `bundle install` and `bundle exec jekyll build`.
